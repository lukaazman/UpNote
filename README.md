# UpNote

A lightweight Markdown editor for Windows. Markdown is styled live in the same
text box you type in: headings, bold, italic, inline code, fenced code blocks,
highlights, sub- and superscript.

Download the [latest release](https://github.com/lukaazman/UpNote/releases/latest).

## Features

- Live in-editor Markdown styling, including ``` fenced code blocks
- Light or Dark theme (starts in your Windows theme until you pick one), with a short crossfade
- Text turns the theme colour where it passes over the logo
- Comfortable side margins around the text
- Remembers theme, zoom, window size and the last open file
- Unsaved-changes marker in the title and a prompt before closing
- Open by drag and drop, or with "Open with" / `UpNote.exe note.md`

## Shortcuts

| Action | Keys |
| --- | --- |
| New / Open / Save / Save As | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| Zoom in | Ctrl + `+` (or `=`), Ctrl + scroll up |
| Zoom out | Ctrl + `-`, Ctrl + scroll down |
| Reset zoom | Ctrl+0 |

Zoom scales the text and the menu bar together.

## Install

1. Open the latest release page.
2. Download the Windows ZIP.
3. Extract it and run `UpNote.exe`.

## Build from source

```powershell
scripts\build.ps1 1.1.0
```

The script creates `.venv` with Python 3.12 if needed, builds a single
`UpNote.exe` with PyInstaller and zips it under `release\`.

Artwork in `assets\` is generated by `python scripts\make_art.py`.
Tests: `python -m unittest discover -s tests`.
